# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature for this repository when it is enabled. If private reporting is unavailable, contact the repository maintainer through a private channel before disclosing technical details publicly.

## Security-sensitive areas

BrahmaAI Studio handles account sessions, project ownership, floor-plan data, and optional local-model integrations. Reports involving authentication, authorization, CSRF, session handling, data exposure, unsafe file handling, or model-service trust boundaries are especially important.

Do not include real credentials, private floor plans, or personal data in issue reports.
